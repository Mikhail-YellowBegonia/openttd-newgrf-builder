# 建筑贴图模板

模板是 AI 出图后的输入和后处理依据。它定义了画布、投影、地面占地、锚点和最大绘制包络；模板辅助线不应进入最终精灵。

## 生成

```sh
.venv/bin/python -m tools.template \
  --output templates/isometric-1x1-h8 \
  --footprint 1x1 \
  --height 8
```

输出 `zi4` 母版和由它派生的低倍率参考图：

- `*.mask.png`：灰度 mask，白色是允许绘制的最大包络，黑色必须保持透明；
- `*.guide.png`：透明辅助图，包含最大包络、tile 菱形、地面原点、地面分割线和一 tile 标尺。

`zi4` 是唯一的创作母版；`normal` 和 `zi2` 的 mask/guide 只是最近邻派生的 QA 参考。guide 采用黑底、白色最大包络和地面边缘红色 `40m` 双向箭头，白色表示“允许绘制的最大区域”，不表示必须填满。`spec.json` 记录全部尺寸和锚点。`normal`、`zi2`、`zi4` 的 tile 网格分别为 `64x32`、`128x64`、`256x128` 像素；一 tile 在项目世界尺度中固定为 40 米。

屏幕投影角度由 2:1 tile 比例决定：地面边相对水平线约为 `26.565°`，从地面下角看两条上行边的夹角约为 `126.87°`。三维等距坐标轴的 `120°` 夹角不能直接当作 PNG 屏幕像素中的角度。

对于正交但采用约 30° 等距投影的输入图，工单可以使用 `projection_mode=orthographic_affine`。处理器会将两个地面基向量映射到模板基向量，完成投影转换；这一步可能改变屏幕 X/Y 像素比例，但不引入透视收敛。

若两条边的手工角度有小误差，可设置 `source_projection_angle_deg`，以屏幕垂直线为对称轴重建源基底；这比把两条不完全对称的测量值直接用于仿射变换更能保持墙面垂直。

## 接受的最终贴图

最终交给 NewGRF 编译器的创作输入只有 `zi4` RGBA PNG，不是 guide 或 mask。编译器从它派生低倍率精灵：

1. `zi4` 图片尺寸必须与 `spec.json` 的 `zi4.canvas` 完全一致；
2. alpha 为 0 的像素必须覆盖 `zi4.mask.png` 为 0 的区域；
3. 建筑可以在包络内留透明像素，包络只是最大边界，不是要求填满；
4. 地面接触点必须落在 anchor，不能把画布边缘当作建筑原点；anchor 是地面菱形的下角；
5. normal/zi2 只能由 zi4 按整数倍率最近邻降采样得到，不接受单独生成或双线性插值；
6. 最终文件不得包含辅助线、标尺或 mask 颜色。

这里的 `mask.png` 是项目的最大包络输入约束，不等同于 NewGRF 运行时的 8bpp recolour mask；当前建筑素材使用 RGBA 透明通道交付。OpenTTD LOD 的颗粒感由最近邻缩小保留。

## 多 tile 和超限建筑

`--footprint WxD` 生成一个连续建筑的完整包络。`spec.json` 的每个 zoom 都包含 `tile_polygons`，用同一画布坐标给出每个 tile 的四个地面角点。编译前再按这些固定角点切成 `W*D` 个 tile 精灵：每个 tile 使用同一 ground projection 和同一 anchor 坐标系，切缝只允许落在 tile 菱形边界上。建筑主体跨越切缝时，必须在相邻 tile 的两个图像中各保留必要的重叠像素，不能按非透明像素自动紧裁。

超出单个 House tile 的建筑必须先决定是：

- 多 tile House：每个 tile 有独立 Action 0/1/2/3 记录和固定 north tile 顺序；
- 预制单体变体：把完整建筑作为一个可替换的多 tile 组合；
- 降级为不接受的素材：无法稳定切分、锚定或重绘的图像不进入构建。

切分工具和 House 多 tile 编译尚未接入首个 PNG 原型，但模板已经固定了其输入坐标系。
