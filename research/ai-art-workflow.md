# 参考图驱动的建筑素材工作流

Gemini 的实验表明，单独把技术模板交给模型，模型容易忽略等距投影、地面和比例约束，还可能把辅助线当成最终画面。加入成熟的等距建筑参考图、建筑实景参考和手绘草图后，构图和体块稳定性明显提高。

因此，模板主要承担生成后的确定性后处理和验收职责。

## 输入角色

1. **风格/空间参考**：符合目标等距视角和游戏美术风格的建筑图，负责告诉模型“怎样摆、怎样看”；
2. **建筑内容参考**：实景照片、立面、屋顶和材料资料，负责告诉模型“画什么”；
3. **草图参考**：手绘平面或体块草图，可选，用于补充轮廓和组合关系。

`zi4.guide.png` 默认不作为模型的主要空间理解输入。它在生成后用于落位、mask 和比例验收。

## 六步流程

1. 固定一个建筑任务的风格参考、建筑参考和草图版本，并记录来源。
2. 用 GPT Image 系列生成 zi4 建筑候选；Gemini 作为对照。候选进入 `assets/generated/`。
3. 人工选择并清理背景、天空、道路、网格、比例尺、文字、水印、悬浮阴影和无关物体。
4. 将清理后的候选缩放、平移到 zi4 模板：地面接触点对齐 anchor，轮廓落在最大包络内。白色区域是允许绘制的最大范围，不要求填满。
5. 检查透明边缘、底部、阴影、比例和视角，通过后进入 `assets/approved/`。
6. 构建器从 zi4 母版用最近邻派生 zi2 和 normal，再编译 NewGRF。

## 状态流转

```text
reference-board -> generated -> selected -> cleaned -> fitted-zi4 -> approved -> released
```

任何带背景、参考线、比例尺或未经落位的候选都不能进入 `approved`。
