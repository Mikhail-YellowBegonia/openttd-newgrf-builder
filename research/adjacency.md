# 邻接建筑实验：Action 2 / VarAction2

状态：调研中，不能作为首版阻塞项。

## 目标

让同一建筑族根据相邻 tile 自动选择：独立体、左/右端头、中段、内角、外角等图形，从而形成连续街墙、院落或成排住宅。

## 需要验证的能力

1. House feature 是否能从当前 tile 的 callback 上下文读取相邻 tile。
2. 可读取变量是否足以区分“本 NewGRF 的同族建筑”，而不误判其他建筑。
3. 多 tile house 的 north tile、组成 tile 与相邻普通 house 如何区分。
4. 建造、拆除、城镇自动替换后，邻居是否会触发重新求值和重绘。
5. multiplayer 与存档加载时，随机分支是否保持确定性。

## 最小原型

- 使用一个 1x1 house ID 和三套明显不同的测试图形：孤立、端头、中段。
- 仅检测东西两侧，先把邻接状态压缩为 2-bit mask。
- 用 VarAction2 根据 mask 选择 sprite layout。
- 分别测试玩家场景编辑器放置、城镇自然生长、拆除、替换、读档和联机同步。

## 退出条件

只有在规范变量、重新求值时机和确定性均通过验证后，才将该机制推广到正式素材。若 house feature 无法可靠读取邻居，则退回“同一建筑内部的多 tile 组合”或预制连续建筑变体。
